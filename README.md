# Sistema Assistivo Integrado

Aplicação desenvolvida em **Python** que reúne recursos de acessibilidade digital para auxiliar pessoas com baixa visão, fotofobia e dificuldades de leitura.

O projeto integra funcionalidades de ampliação de tela, reconhecimento de texto, síntese de voz e personalização visual em uma única aplicação, buscando proporcionar uma experiência mais acessível e independente durante o uso do computador.

## Recursos

- **Lupa virtual:** ampliação de regiões da tela com diferentes níveis de zoom.
- **OCR:** reconhecimento e extração de texto a partir de imagens e conteúdos exibidos na tela.
- **Síntese de voz (TTS):** leitura de textos em voz alta, com controles de reprodução.
- **Contraste visual:** diferentes modos de exibição para facilitar a leitura e reduzir o desconforto visual.
- **Temas:** opções de aparência clara e escura.
- **Atalhos globais:** acesso rápido às principais funcionalidades.
- **Configurações personalizadas:** armazenamento das preferências do usuário.

## Como executar

### Requisitos

- Python instalado.
- Dependências listadas em `requirements.txt`.

### Instalação

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Acesse a pasta do projeto:

```bash
cd NOME_DO_REPOSITORIO
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute a aplicação:

```bash
python main.py
```

## Testes

Para executar os testes automatizados:

```bash
python test_assistive_app.py
```

## Objetivo do projeto

O Sistema Assistivo Integrado tem como objetivo explorar o uso da Tecnologia Digital da Informação e Comunicação (TDIC) em conjunto com a Tecnologia Assistiva (TA), contribuindo para a acessibilidade digital e a inclusão de pessoas com diferentes necessidades visuais e de leitura.
